# ТехноМир — лабораторные работы 3, 4, 6, 7 и 8

Тема сайта — магазин электроники. Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

После этого перейдите на `http://localhost:8000`.

## Как показывать работу преподавателю

1. На главной странице покажите шапку, блок «Популярные товары» и подвал. У товаров видны подписи **JPEG**, **PNG** и **SVG**.
2. Нажмите «Регистрация» в шапке. На этой странице покажите две группы формы, обязательные поля и кнопку.
3. Поставьте галочку «Утро» или выберите «Женский»: текст рядом с выбранным элементом станет зачёркнутым. Это `input:checked + label`.
4. Наведите курсор на ссылку или кнопку, затем нажмите на ней и перейдите на неё клавишей `Tab`: это демонстрирует `:hover`, `:active` и `:focus-visible`.
5. Выделите мышью часть текста: выделение станет синим благодаря `::selection`.
6. Внизу формы покажите список «Примеры псевдоэлементов»: нечётные и чётные пункты имеют разный цвет, а `::before` и `::after` добавляют текст.

## Шпаргалка по требованиям

| ЛР | Где видно на сайте | Где находится код |
| --- | --- | --- |
| 3 | Цвета, шрифт, кнопки и карточки | `css/style.css`: строки с `@import`, `body`, `a`, `.button`, `.product-card` |
| 4 | Карточки, бейдж «Хит», адаптивная сетка | `css/style.css`: `* { box-sizing }`, `.product-card`, `.product-badge`, `.container` |
| 6 | Три карточки с JPEG, PNG и SVG | `index.html`: блок `.product-grid`; `css/style.css`: `.product-card img` с `object-fit` |
| 7 | Страница регистрации | `form.html`: `<form>`, `<fieldset>`, `type`, `required`, `placeholder`; `css/style.css`: `.form-page` |
| 8 | Форма и список псевдоэлементов | `css/style.css`: `::selection`, `:hover`, `:active`, `:focus-visible`, `:checked`, `::placeholder`, `.pseudo-list` |

## Какие скриншоты делать

1. **Браузер, главная:** откройте `index.html`, прокрутите так, чтобы в кадре были заголовок «Популярные товары» и все три карточки с подписями JPEG, PNG, SVG.
2. **Браузер, форма:** откройте `form.html`, отметьте «Утро», чтобы было видно зачёркивание, и снимите обе группы полей и список псевдоэлементов.
3. **Код CSS:** откройте `css/style.css`, выделите от `@import` до `.button` — там видны требования ЛР3 и ЛР8.
4. **Код HTML:** откройте `form.html`, выделите содержимое `<form>` с двумя `<fieldset>` — там видны требования ЛР7.

На macOS сделайте снимок экрана сочетанием `Shift + Command + 4`, выделите нужную область и щёлкните. Снимок сохранится на рабочем столе. В Word: **Вставка → Рисунки → Это устройство**, выберите снимок.

## Git и GitHub

Перед отправкой выполните в папке проекта:

```bash
git add index.html form.html css/style.css images README.md
git commit -m "Добавлены лабораторные работы 3 4 6 7 8"
git push
```

После `git push` скопируйте адрес репозитория из браузера GitHub и замените строку-заглушку в отчёте.
